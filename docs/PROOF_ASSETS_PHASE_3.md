# Proof assets — Phase 3

## Creative direction
Move the Advisory page from *claims about experience* toward *evidence of how the work is structured*. The visual language should feel like an executive working artifact: sober, precise, schematic and immediately legible.

## Experience architecture
The Advisory journey now resolves in four layers:
1. how the decision system changes,
2. what a concrete portfolio decision artifact can look like,
3. which disciplines are connected,
4. three anonymized proof blueprints showing real problem logic.

The proof layer deliberately replaces a longer catalogue of cases. Each selected example carries context, challenge, intervention, management value and a schematic reconstruction of the decision logic.

## Proof blueprint set
- **Portfolio rationalization** — initiatives converge on shared capability constraints and explicit stop / merge / sequence / continue choices.
- **Euro impact analysis** — a cross-system impact map makes the blast radius visible across processes, data, systems, integrations, reporting and settlement.
- **Governance** — a fragmented forum pattern is contrasted with an explicit owner → evidence → decision → review loop.

## Integrity guardrails
- no client names or logos,
- no invented KPI or pseudo-precision,
- diagrams are labelled and described as schematic,
- existing case-study copy remains the factual source,
- SVG artifacts are presentation-only; the semantic explanation remains in HTML,
- no new client JavaScript and no new CSS layer.

## Performance rationale
The diagrams are inline SVG using presentation attributes rather than a new visual CSS system. This keeps the strict CSS budget untouched while adding richer proof surfaces. The work page becomes heavier only in static HTML, with no additional runtime dependency.

## Next useful proof material
The strongest future upgrade would be real, publishable source material: workshop/whiteboard photography, an anonymized deliverable crop, or a speaking image. Until those assets exist with clear publication rights, generated or staged imagery should not be presented as evidence of client work.
