## OAF i architektura organizacyjna — punkty odniesienia
Strona nie przedstawia organizational architecture jako autorskiego wynalazku Arkadiusza Kamrowskiego. OAF jest pozycjonowany jako **praktyczna synteza istniejących nurtów**, rozszerzona o logikę portfolio, wykonania i evidence/feedback.

## Zasada dotycząca OAF
- „Organizational Architecture Framework” na tej stronie oznacza nazwę roboczej syntezy i języka decyzji.
- Nie publikujemy twierdzenia, że skrót OAF jest jednym powszechnie uznanym standardem branżowym.
- Autorski wkład jest formułowany jako **integracja i sposób zastosowania**: Direction → Architecture/Choices → Portfolio/Priorities → Execution/Evidence, z pętlą zwrotną evidence → kolejna decyzja.
- Pełny metamodel, ontologia i formalna metoda wymagają dalszego opracowania i nie są obecnie deklarowane jako ukończony standard.
